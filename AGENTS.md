# Agent entry point

For a request that combines any two or more of the following — raw product data,
interviews, research notes, the user's own thinking, hypotheses, goals, or
experiment results — read and apply:

`skills/product-research-synthesis/SKILL.md`

Do not preload every upstream skill. Follow the router and token budget. Treat
the user's interpretations as `USER_BELIEF`, not as evidence. Preserve source
locators for every material finding.
